# Конструктор инструкций

Локальный MVP на Streamlit для формирования внутренних и внешних инструкций, автоматической предварительной проверки, доработки по замечаниям, ручного согласования и экспорта.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m streamlit run app.py
```

Для предпросмотра через Kimi Work:

```bash
npm run dev -- --host 0.0.0.0 --port 7100
```

## Настройка LLM

Скопируйте `.env.example` в `.env` и самостоятельно заполните:

- `OPENAI_API_KEY` — ключ OpenAI-совместимого API;
- `OPENAI_MODEL` — модель;
- `OPENAI_BASE_URL` — базовый URL, по умолчанию `https://api.openai.com/v1`;
- `OPENAI_TIMEOUT` — необязательный таймаут в секундах, по умолчанию 120.

Ключ не вводится в интерфейсе и не сохраняется в истории. Без настройки API доступны оценка вставленного черновика, сравнение версий, метрики и экспорт. Демонстрационный черновик загружается кнопкой в боковой панели.

## Сценарий

1. Выберите внутренний или внешний тип и заполните пять обязательных блоков вводных.
2. Для внешней инструкции загрузите системный промпт, правила, шаблон и пример в UTF-8, до 2 МБ каждый.
3. Сформируйте черновик или вставьте существующий Markdown на второй вкладке.
4. Нажмите «Оценить черновик». При балле ниже 85 или любом критическом замечании рекомендуется доработка.
5. Внесите правки вручную или отправьте замечания в LLM. После доработки проверьте diff и процент изменённых строк.
6. Зафиксируйте вердикт человека, сохраните метрики и выгрузите MD/DOCX.

## Метрики

- Подтверждённость источником — 25%: ссылки и UI-названия в «ёлочках» ищутся во вводных и разрешённой базе, пример не используется как источник фактов.
- Структура — 20%; соответствие списка задач заголовкам — 15%; рисунки — 15%; стиль — 15%; читаемость и полнота — 10%.
- Критические: нарушение NEED_INFO, отсутствие структуры, расхождение задач, несуществующие рисунки, неподтверждённые URL/UI, отсутствие блока уточнений при наличии меток.
- После доработки дополнительно считаются доля изменённых строк и similarity.

Балл — воспроизводимый triage, а не доказательство фактической корректности. Согласование остаётся за человеком. В `data/metrics.jsonl` сохраняются только метаданные оценок, без ТЗ и текста документа.

## Тесты

```bash
.venv/Scripts/python -m pytest -q
```

Тесты используют подменённый транспорт LLM и не обращаются к реальному API.

## Ограничения MVP

- Реальные скриншоты не создаются: сохраняются метки `[СКРИНШОТ: …]` и подписи по правилам.
- Встроенной внешней базы знаний нет, поскольку исходные материалы не были приложены.
- Эвристика проверки императивов, длинных предложений и источников может давать ложные срабатывания; все спорные элементы показываются человеку.
- Цели пилота не являются измеренными результатами: для времени, доли принятия и качества NEED_INFO нужны baseline и размеченная выборка.
