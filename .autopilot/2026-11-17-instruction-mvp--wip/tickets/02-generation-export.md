## Что должно заработать

Внутренняя база знаний загружается из приложений; внешняя принимается через файлы. Настроенный OpenAI-совместимый API формирует и дорабатывает документ. Без API проверка и экспорт продолжают работать. MD/DOCX и локальная JSONL-история метрик доступны без передачи содержимого документов в историю.

## Критерии приёмки

- [ ] Внутренние системный промпт, правила, шаблон и пример подключены
- [ ] Внешняя генерация без четырёх материалов блокируется с объяснением
- [ ] Обязательные вводные проверяются до API; ошибки API безопасны и не раскрывают ключ
- [ ] Доработка включает текущий текст и только перечисленные замечания
- [ ] DOCX сохраняет основную структуру, Markdown скачивается в UTF-8
- [ ] История хранит только метрики и устойчива к повреждённой строке
