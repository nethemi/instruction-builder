# 03 — Streamlit-сценарий и приёмка MVP

**Требования:** R01–R12i
**Blocked by:** 01, 02
**Зона:** `app.py`, конфигурация запуска, документация, интеграционные тесты
**Волна:** 3
**Status:** ready

## Что должно заработать

Один понятный интерфейс ведёт от вводных к черновику, оценке, доработке, ручному согласованию и выгрузке. Состояние не теряется при ошибках, демо-черновик позволяет проверить приложение без API, метрики и причины решения видны пользователю.

## Критерии приёмки

- [ ] Вкладки составления, проверки/доработки и метрик/согласования работают на общих данных
- [ ] Обязательные поля и загрузки валидируются; пустые и ошибочные состояния понятны
- [ ] Демо загружает приложенный проблемный черновик и показывает нарушение контракта
- [ ] Ручной вердикт и локальная история сохраняются; агрегаты не выдаются за baseline
- [ ] MD и DOCX скачиваются из итогового экрана
- [ ] Полный набор тестов зелёный, Streamlit запускается, README содержит команды и ограничения
